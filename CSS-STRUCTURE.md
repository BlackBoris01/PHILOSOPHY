# Модульная структура CSS файлов

## Описание

CSS код проекта организован в модульную структуру для максимальной гибкости и поддержки:

```
css/
├── base.css                    # Базовые стили для всех страниц
├── main.css                    # Главный файл с импортами (опционально)
├── components/                 # Переиспользуемые компоненты (будущее развитие)
└── pages/                      # Стили для конкретных страниц
    ├── home/
    │   └── home.css           # Стили главной страницы
    ├── about/
    │   └── about.css          # Стили страницы "О музее"
    ├── exhibitions/
    │   └── exhibitions.css    # Стили страницы "Выставки"
    ├── events/
    │   └── events.css         # Стили страницы "События"
    ├── contacts/
    │   └── contacts.css       # Стили страницы "Контакты"
    └── news/
        └── news.css           # Стили страниц новостей
```

## Файлы и их назначение

### `css/base.css` - Базовые стили
Содержит общие стили для всех страниц:
- **CSS переменные** (цвета, размеры, тени)
- **Базовые стили** (сброс, типографика, изображения)
- **Хедер и навигация** (включая мобильное меню)
- **Футер и социальные ссылки**
- **Общие UI элементы** (кнопки, формы)
- **Эффекты и анимации**
- **Базовая адаптивность**

### Страничные CSS файлы
Каждая страница имеет свой CSS файл с соответствующими стилями:

- **`home.css`** - Hero секция, новости, факты, превью событий, карточки платформ
- **`about.css`** - Сетка контента, команда, цитаты, информационные карточки
- **`exhibitions.css`** - Карточки выставок, галереи, статусы, информация о посещении
- **`events.css`** - Фильтры событий, карточки мероприятий, регулярные программы
- **`contacts.css`** - Контактная информация, формы, карты, реквизиты, транспорт
- **`news.css`** - Статьи, оглавление, партнеры, мета-информация

### `css/main.css` - Главный файл (опционально)
Содержит импорты всех CSS модулей. Можно использовать для загрузки всех стилей одним файлом.

## Подключение в HTML

Каждая страница подключает только необходимые CSS файлы:

```html
<!-- Главная страница -->
<link rel="stylesheet" href="css/base.css" />
<link rel="stylesheet" href="css/pages/home/home.css" />

<!-- Страница "О музее" -->
<link rel="stylesheet" href="css/base.css" />
<link rel="stylesheet" href="css/pages/about/about.css" />

<!-- Альтернативный вариант - один файл со всеми стилями -->
<link rel="stylesheet" href="css/main.css" />
```

## Преимущества модульной структуры

1. **🎯 Точечная загрузка** - каждая страница загружает только нужные стили
2. **📦 Модульность** - легко найти и изменить стили конкретной страницы
3. **♻️ Переиспользование** - общие стили в base.css не дублируются
4. **⚡ Производительность** - меньший размер CSS файлов на странице
5. **🛠️ Поддержка** - проще добавлять новые страницы
6. **👥 Командная работа** - разные разработчики могут работать с разными модулями
7. **📖 Читаемость** - четкое разделение ответственности

## Рекомендации по развитию

### Добавление новой страницы:
1. Создайте папку `css/pages/new-page/`
2. Создайте файл `css/pages/new-page/new-page.css`
3. Добавьте импорт в `css/main.css` (если используется)
4. Подключите CSS в HTML файле страницы

### Создание переиспользуемых компонентов:
1. Создайте файл в `css/components/component-name.css`
2. Добавьте импорт в `css/base.css` или в конкретные страницы
3. Используйте CSS переменные из `base.css`

### Оптимизация производительности:
- Используйте только необходимые CSS файлы на каждой странице
- Рассмотрите объединение часто используемых компонентов в `base.css`
- Минифицируйте CSS файлы для продакшена

## Миграция и обновление

При добавлении новых стилей:
- **Общие стили** → `css/base.css`
- **Стили конкретной страницы** → соответствующий файл в `css/pages/`
- **Новые компоненты** → `css/components/` (для будущего развития)

Эта структура обеспечивает максимальную гибкость и масштабируемость проекта.
