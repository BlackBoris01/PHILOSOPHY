# Музей философии - React Frontend

Современное веб-приложение для музея философии, построенное на React + TypeScript.

## Особенности

- 🎨 Современный дизайн с адаптивной версткой
- 📱 Мобильная версия
- 🚀 Быстрая загрузка и плавные анимации
- 📰 Система новостей с админ панелью
- 🔗 Интеграция с REST API

## Технологии

- **React 18** - библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript
- **React Router** - маршрутизация
- **Webpack** - сборка проекта
- **CSS3** - стилизация с современными возможностями

## Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер разработки:

```bash
npm start
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

### Быстрый запуск

Для Windows:

```bash
start.bat
```

Для Linux/Mac:

```bash
./start.sh
```

### Очистка кэша (если медленно загружается)

```bash
npm start -- --clean
# или
start.bat --clean
```

## Сборка для продакшена

```bash
npm run build
```

## Админ панель

Админ панель доступна по адресу `/admin` и позволяет:

- Просматривать все новости
- Создавать новые новости
- Редактировать существующие новости
- Удалять новости

## API интеграция

Приложение интегрировано с Node.js API сервером:

- Получение списка новостей
- Получение детальной информации о новости
- Создание, обновление и удаление новостей

В случае недоступности API используются моковые данные для демонстрации функциональности.

## Решение проблем

### 🐌 Медленная загрузка (20-30 секунд)

**Причина:** Webpack компилирует всё с нуля каждый раз.

**Решение:**

1. Очистите кэш: `npm start -- --clean`
2. Перезапустите сервер
3. Первая загрузка будет медленной, последующие - быстрыми

### ❌ "Cannot GET /exhibitions" при обновлении страницы

**Причина:** Неправильная настройка `historyApiFallback`.

**Решение:**

1. Убедитесь что используете последнюю версию webpack.config.js
2. Перезапустите сервер: `npm start`
3. Используйте навигацию через меню, а не обновление страницы

### 🔧 Другие проблемы

**Порт занят:**

```bash
# Найдите процесс на порту 3000
netstat -ano | findstr :3000
# Завершите процесс
taskkill /PID <PID> /F
```

**Стили не применяются:**

1. Очистите кэш браузера (Ctrl+F5)
2. Перезапустите сервер

**Изображения не загружаются:**

1. Проверьте что файлы есть в `src/assets/`
2. Убедитесь что импорты корректны в компонентах
