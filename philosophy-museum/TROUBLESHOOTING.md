# Руководство по устранению проблем

## Проблема: Стили не применяются и изображения не отображаются

### Решение

Все статические ресурсы (изображения, иконки) должны быть импортированы как модули в React компонентах.

### Что было исправлено:

1. **Webpack конфигурация**

   - Добавлена поддержка `.jfif` и `.ico` файлов
   - Настроен `devServer.static` для обслуживания статических файлов из `public`
   - Добавлен генератор имен файлов для сохранения оригинальных имен

2. **Изображения перенесены в `src/assets/`**

   - `backgroundHome.jfif` - фоновое изображение главной страницы
   - `discus-thrower-sculpture.jpg` - скульптура дискобола
   - `philosophy-museum-logo.png` - логотип музея
   - `favicon.ico` - иконка сайта

3. **TypeScript декларации**

   - Создан файл `src/custom.d.ts` с декларациями для импорта изображений

4. **Обновлены компоненты:**
   - `Header.tsx` - импортирует и использует логотип
   - `Footer.tsx` - импортирует и использует логотип
   - `Home.tsx` - импортирует фоновое изображение и скульптуру
   - `Exhibitions.tsx` - импортирует скульптуру
   - `newsService.ts` - использует импортированное изображение для новостей

### Как использовать изображения:

```tsx
// 1. Импортируйте изображение
import myImage from "../assets/my-image.jpg";

// 2. Используйте в JSX
<img src={myImage} alt="Описание" />;
```

### После внесения изменений:

1. Остановите dev server если он запущен (Ctrl+C)
2. Перезапустите: `npm start`
3. Откройте браузер на http://localhost:3000
4. Очистите кеш браузера (Ctrl+Shift+R или Cmd+Shift+R)

### Проверка работы:

1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Обновите страницу
4. Проверьте, что изображения загружаются (статус 200)
5. Проверьте, что CSS файл загружается

### Если проблемы остаются:

1. Удалите папку `dist`:

   ```bash
   rm -rf dist
   ```

2. Очистите кеш npm:

   ```bash
   npm cache clean --force
   ```

3. Переустановите зависимости:

   ```bash
   rm -rf node_modules
   npm install
   ```

4. Перезапустите dev server:
   ```bash
   npm start
   ```
